### ⚠️ 已知问题和限制

#### 搜索功能限制

- [⏭️] **FTS5 查询逻辑未完整实现**
  - **影响**: 搜索命令可用但返回空结果
  - **严重性**: 🟡 中等（功能可用，但实际效果有限）
  - **临时方案**: 使用 `/list` 浏览会话列表
  - **修复计划**: V3.2 完善 FTS5 查询逻辑
  - **是否阻塞发布**: ❌ 否（已在文档中说明）

- [⏭️] **搜索结果无分页 UI**
  - **影响**: 结果过多时需要手动指定 `--page` 参数
  - **严重性**: 🟢 低（有命令行参数替代方案）
  - **临时方案**: 使用 `--page-size` 和 `--page` 参数
  - **修复计划**: V3.2 添加交互式分页 UI
  - **是否阻塞发布**: ❌ 否

#### 标签功能限制

- [⏭️] **LLM 超时策略固定**
  - **影响**: 网络不稳定时可能超时失败
  - **严重性**: 🟢 低（有重试机制）
  - **临时方案**: 重试命令
  - **修复计划**: V3.2 添加可配置超时参数
  - **是否阻塞发布**: ❌ 否

- [⏭️] **标签重命名不支持**
  - **影响**: 需要删除并重新添加
  - **严重性**: 🟢 低（有手动操作替代方案）
  - **临时方案**: `/tag remove` + `/tag add`
  - **修复计划**: V3.2 添加 `/tag rename` 命令
  - **是否阻塞发布**: ❌ 否

#### 性能限制

- [⏭️] **缓存容量固定**
  - **影响**: 高频使用场景下命中率可能下降
  - **严重性**: 🟢 低（当前命中率 72%）
  - **临时方案**: 无需临时方案
  - **修复计划**: V3.2 添加可配置缓存容量
  - **是否阻塞发布**: ❌ 否

**结论**: ⚠️ 有已知限制，但均不阻塞发布。所有限制已在文档中说明。
