## 🧪 命令测试

### 2. /help 命令

**操作**: 输入 `/help` 并回车

**验收标准**:
- [ ] 显示命令表格（圆角边框）
- [ ] 列出 7 个命令（/help, /new, /list, /switch, /provider, /history, /exit）
- [ ] 每个命令有说明

### 3. /provider 命令

**操作**: 输入 `/provider` 并回车

**验收标准**:
- [ ] 显示当前提供商（Ollama）
- [ ] 显示可用提供商列表（Ollama, LMStudio, llamacpp, OMLX）

### 4. /new 命令（无标题）

**操作**: 输入 `/new` 并回车

**验收标准**:
- [ ] 显示成功消息（绿色）
- [ ] 显示新会话标题（"新会话"）
- [ ] 显示会话 ID

### 5. /new 命令（有标题）

**操作**: 输入 `/new 测试会话标题` 并回车

**验收标准**:
- [ ] 显示成功消息
- [ ] 显示自定义标题（"测试会话标题"）
- [ ] 显示会话 ID

### 6. /list 命令

**操作**: 输入 `/list` 并回车

**验收标准**:
- [ ] 显示会话表格（圆角边框）
- [ ] 包含列：ID, 标题, 消息数, 创建时间
- [ ] 当前会话有绿色 "*" 标记
- [ ] 至少显示 3 个会话（默认会话 + 2 个新建会话）
- [ ] ID 显示前 8 位 + "..."
- [ ] 创建时间格式正确（yyyy-MM-dd HH:mm）

### 7. /switch 命令（无参数）

**操作**: 输入 `/switch` 并回车

**验收标准**:
- [ ] 显示错误消息（红色）
- [ ] 提示用法："用法: /switch <provider>"
- [ ] 显示当前提供商和可用提供商

### 8. /switch 命令（无效提供商）

**操作**: 输入 `/switch InvalidProvider` 并回车

**验收标准**:
- [ ] 显示错误消息："未知提供商: InvalidProvider"
- [ ] 显示当前提供商和可用提供商

### 9. /switch 命令（有效提供商）

**操作**: 输入 `/switch LMStudio` 并回车

**验收标准**:
- [ ] 显示成功消息："已切换到提供商: LMStudio"
- [ ] 后续对话使用新提供商（如果 LMStudio 未运行会报错，这是正常的）

**恢复**: 输入 `/switch Ollama` 切回默认提供商

### 10. /history 命令（空会话）

**操作**:
1. 输入 `/new 空会话`
2. 输入 `/history`

**验收标准**:
- [ ] 显示："会话历史为空"（黄色）

### 11. /history 命令（有消息）

**操作**:
1. 输入 `/new 历史测试`
2. 输入 `你好`（发送对话）
3. 等待响应完成
4. 输入 `/history`

**验收标准**:
- [ ] 显示标题："会话历史 (共 X 条消息):"
- [ ] 至少显示 2 条消息（1 user + 1 assistant）
- [ ] 用户消息显示 "You>" 前缀（蓝色）
- [ ] 助手消息显示 "Assistant>" 前缀（绿色）
- [ ] 消息内容完整显示

## 💬 对话测试

### 12. 简单对话（非 Ollama）

**注意**: 如果没有 Ollama，应用会使用 MockLLMClient（默认行为）

**操作**: 输入 `你好` 并回车

**验收标准**:
- [ ] 显示 "Assistant>" 前缀（绿色）
- [ ] 显示响应内容（可能是错误消息，如果没有 LLM）
- [ ] 响应完成后显示新的 "You>" 提示符

### 13. 流式对话（需要 Ollama）

**前提**: Ollama 已运行，已执行 `ollama pull qwen2.5:0.5b`

**操作**:
1. 确认当前提供商是 Ollama（`/provider`）
2. 输入 `介绍一下你自己`

**验收标准**:
- [ ] 显示 "Assistant>" 前缀
- [ ] **逐字显示响应**（流式输出）
- [ ] 响应流畅，无明显延迟
- [ ] 响应完成后显示新提示符

### 14. 多轮对话

**操作**:
1. 输入 `你好，我是测试用户`
2. 等待响应
3. 输入 `我刚才说的是什么？`
4. 等待响应

**验收标准**:
- [ ] 第二轮对话能引用第一轮内容
- [ ] 证明会话历史正常工作
- [ ] 所有消息都持久化到数据库

### 15. 长文本对话（可选）

**操作**: 输入一段长文本（200+ 字）

**验收标准**:
- [ ] 应用不崩溃
- [ ] 能正常处理长输入
- [ ] 响应正常

## 🐛 已知问题

### 1. 没有 Ollama 时

**现象**: 对话时报错 "Connection refused" 或类似错误

**解决**:
- 安装 Ollama: `brew install ollama`
- 启动服务: `ollama serve`
- 拉取模型: `ollama pull qwen2.5:0.5b`

### 2. 数据库锁定

**现象**: 多个实例同时运行时可能出现数据库锁定

**解决**: 确保只运行一个实例
