## 📋 执行摘要

本设计规范描述了 General Agent V3.1 的两个核心功能：

1. **智能消息搜索** - 支持自然语言查询的增强搜索系统
2. **智能标签系统** - 基于 LLM 的自动标签建议和管理

**设计目标**:
- 自然语言查询理解（用户友好）
- 智能标签建议（基于标题和内容）
- 性能优化（搜索 < 300ms，标签建议 < 2s）
- 成本可控（查询缓存 + 异步处理）

**技术方案**: 平衡优化方案
- LLM 用于关键场景（查询理解、标签建议）
- SQLite FTS5 全文索引
- LRU 查询缓存
- 后台异步任务队列

## 🎯 需求分析

### 功能需求

#### FR1: 智能消息搜索

**FR1.1 自然语言查询**
- 用户可以用自然语言描述搜索需求
- 示例: "查找昨天关于 Python 的讨论"、"我问的所有问题"
- 系统使用 LLM 理解查询意图并转换为结构化查询

**FR1.2 查询缓存**
- 相似查询（Levenshtein 距离 < 3）复用已缓存的查询计划
- LRU 缓存策略，容量 100 条，TTL 1 小时
- 缓存命中时跳过 LLM 调用

**FR1.3 搜索能力**
- 支持关键词搜索（大小写不敏感）
- 支持正则表达式搜索
- 支持精确短语匹配
- 支持字段过滤（role、session_id、时间范围）

**FR1.4 结果展示**
- 高亮匹配的关键词
- 显示上下文摘要（前后各 100 字符）
- 结果分页（默认 50 条）
- 支持导出为 JSON 格式

**FR1.5 性能要求**
- 搜索响应时间 < 300ms（1000 条消息）
- LLM 查询理解 < 2s（首次）
- 缓存命中率 > 80%（常见查询）

#### FR2: 智能标签系统

**FR2.1 标签建议 - 基于标题**
- 用户创建会话时，系统分析标题并建议 2-3 个标签
- 响应时间 < 2s
- 用户可以接受、拒绝或修改建议

**FR2.2 标签建议 - 基于内容**
- 会话有 5+ 消息后，后台任务自动分析完整内容
- 生成 3-5 个标签建议
- 用户无感知，下次查看会话时显示新标签

**FR2.3 手动标签管理**
- 用户可以手动添加、删除标签
- 每个会话最多 5 个标签
- 标签大小写不敏感，统一小写存储
- 标签去重（同一会话不能有重复标签）

**FR2.4 标签属性**
- 标签名称（必填，1-2 个词）
- 标签颜色（可选，十六进制 RGB）
- 标签图标（可选，Emoji）
- 标签来源（User 或 Auto）

**FR2.5 标签过滤**
- 用户可以按标签过滤会话列表
- 支持单标签过滤：`/list --tag work`
- 支持多标签 AND 过滤：`/list --tag work,urgent`
- 支持多标签 OR 过滤：`/list --tag-any work,bug`

**FR2.6 标签统计**
- 显示所有标签及使用次数
- 按使用频率排序
- 支持点击标签快速过滤

### 非功能需求

**NFR1: 性能**
- 搜索响应时间 < 300ms（1000 条消息）
- 标签建议响应时间 < 2s（标题）/ < 10s（内容）
- 后台任务不阻塞主线程
- 内存占用增长 < 20MB

**NFR2: 可靠性**
- LLM 调用失败时的回退机制
- 数据库操作的事务保证
- 并发控制（防止标签重复添加）

**NFR3: 可维护性**
- 代码测试覆盖率 > 85%
- 清晰的分层架构
- 完整的 XML 文档注释

**NFR4: 成本控制**
- 查询缓存减少 LLM 调用
- 后台任务异步处理（不阻塞用户）
- LLM 调用超时机制（5s）

#### messages_fts 虚拟表（新增）

```sql
-- FTS5 全文索引表
CREATE VIRTUAL TABLE messages_fts USING fts5(
    message_id UNINDEXED,
    session_id UNINDEXED,
    content,
    role UNINDEXED,
    created_at UNINDEXED,
    content='messages',
    content_rowid='id'
);

-- 触发器：自动同步 messages 表到 FTS 表
CREATE TRIGGER messages_ai AFTER INSERT ON messages BEGIN
    INSERT INTO messages_fts(message_id, session_id, content, role, created_at)
    VALUES (new.id, new.session_id, new.content, new.role, new.created_at);
END;

CREATE TRIGGER messages_ad AFTER DELETE ON messages BEGIN
    DELETE FROM messages_fts WHERE message_id = old.id;
END;

CREATE TRIGGER messages_au AFTER UPDATE ON messages BEGIN
    DELETE FROM messages_fts WHERE message_id = old.id;
    INSERT INTO messages_fts(message_id, session_id, content, role, created_at)
    VALUES (new.id, new.session_id, new.content, new.role, new.created_at);
END;
```

**设计说明**:
- FTS5 提供全文搜索能力（比 LIKE 快 10-100 倍）
- 触发器保证数据自动同步
- `UNINDEXED` 字段不参与全文索引，仅用于结果过滤

## 🔧 核心服务设计

### NaturalLanguageQueryService

**职责**: 将自然语言查询转换为结构化的 SearchCriteria

**核心方法**:

```csharp
namespace GeneralAgent.Application.Services;

/// <summary>
/// 自然语言查询服务
/// </summary>
public sealed class NaturalLanguageQueryService
{
    private readonly ILLMClient _llmClient;
    private readonly ISearchQueryCache _queryCache;
    private readonly ILogger<NaturalLanguageQueryService> _logger;

    /// <summary>
    /// 解析自然语言查询
    /// </summary>
    /// <param name="naturalQuery">自然语言查询字符串</param>
    /// <param name="ct">取消令牌</param>
    /// <returns>结构化搜索查询</returns>
    public async Task<SearchQuery> ParseQueryAsync(
        string naturalQuery,
        CancellationToken ct = default)
    {
        // 1. 检查缓存
        var cachedQuery = _queryCache.Get(naturalQuery);
        if (cachedQuery != null)
        {
            _logger.LogDebug("查询缓存命中: {Query}", naturalQuery);
            return cachedQuery;
        }

        // 2. 调用 LLM 解析
        var prompt = BuildParsePrompt(naturalQuery);

        using var timeoutCts = new CancellationTokenSource(TimeSpan.FromSeconds(5));
        using var linkedCts = CancellationTokenSource.CreateLinkedTokenSource(ct, timeoutCts.Token);

        try
        {
            var response = await _llmClient.GenerateAsync(prompt, linkedCts.Token);
            var criteria = ParseLLMResponse(response);

            var query = new SearchQuery
            {
                NaturalQuery = naturalQuery,
                Criteria = criteria,
                Type = DetermineSearchType(criteria)
            };

            // 3. 缓存结果
            _queryCache.Set(naturalQuery, query);
            return query;
        }
        catch (OperationCanceledException) when (timeoutCts.IsCancellationRequested)
        {
            _logger.LogWarning("查询解析超时，回退到关键词搜索");
            return FallbackToKeywordSearch(naturalQuery);
        }
        catch (JsonException ex)
        {
            _logger.LogWarning(ex, "LLM 返回无效 JSON，回退到关键词搜索");
            return FallbackToKeywordSearch(naturalQuery);
        }
    }

    private string BuildParsePrompt(string naturalQuery)
    {
        return $@"
你是一个搜索查询解析器。将用户的自然语言查询转换为结构化的搜索条件。

用户查询: {naturalQuery}

请分析查询并返回 JSON 格式的搜索条件：
{{
  ""keywords"": [""关键词1"", ""关键词2""],
  ""exactPhrases"": [""精确短语""],
  ""regexPattern"": ""正则表达式（如果需要）"",
  ""role"": ""user"" | ""assistant"" | null,
  ""sessionId"": ""会话ID"" | null,
  ""startDate"": ""ISO8601日期"" | null,
  ""endDate"": ""ISO8601日期"" | null
}}

示例：
- ""查找昨天关于 Python 的讨论"" → {{""keywords"":[""Python""], ""startDate"":""2026-03-24T00:00:00Z""}}
- ""搜索我问的所有问题"" → {{""keywords"":[], ""role"":""user""}}
- ""包含 'bug fix' 的消息"" → {{""exactPhrases"":[""bug fix""]}}

只返回 JSON，不要其他解释。
";
    }

    private SearchQuery FallbackToKeywordSearch(string query)
    {
        return new SearchQuery
        {
            NaturalQuery = query,
            Criteria = new SearchCriteria { Keywords = new List<string> { query } },
            Type = SearchType.Keyword
        };
    }
}
```

**LLM 提示词设计原则**:
- 清晰的任务描述
- 具体的输出格式（JSON Schema）
- 充分的示例（few-shot learning）
- 强调约束（只返回 JSON）

### SmartTagService

**职责**: 分析会话内容并生成标签建议

**核心方法**:

```csharp
namespace GeneralAgent.Application.Services;

/// <summary>
/// 智能标签服务
/// </summary>
public sealed class SmartTagService
{
    private readonly ILLMClient _llmClient;
    private readonly ISessionTagRepository _tagRepository;
    private readonly ISessionRepository _sessionRepository;
    private readonly IMessageRepository _messageRepository;
    private readonly ILogger<SmartTagService> _logger;

    /// <summary>
    /// 基于会话标题建议标签（快速）
    /// </summary>
    /// <param name="title">会话标题</param>
    /// <param name="ct">取消令牌</param>
    /// <returns>标签建议列表</returns>
    public async Task<List<TagSuggestion>> SuggestFromTitleAsync(
        string title,
        CancellationToken ct = default)
    {
        var prompt = $@"
为以下会话标题生成 2-3 个标签：

标题: {title}

要求：
1. 标签简洁（1-2 个词）
2. 小写英文或中文
3. 每个标签附带合适的颜色（十六进制）和 Emoji

返回 JSON 数组：
[
  {{""tag"": ""work"", ""color"": ""#3B82F6"", ""emoji"": ""💼""}},
  {{""tag"": ""bug"", ""color"": ""#EF4444"", ""emoji"": ""🐛""}}
]

只返回 JSON 数组，不要其他解释。
";

        using var timeoutCts = new CancellationTokenSource(TimeSpan.FromSeconds(5));
        using var linkedCts = CancellationTokenSource.CreateLinkedTokenSource(ct, timeoutCts.Token);

        try
        {
            var response = await _llmClient.GenerateAsync(prompt, linkedCts.Token);
            return ParseTagSuggestions(response);
        }
        catch (OperationCanceledException) when (timeoutCts.IsCancellationRequested)
        {
            _logger.LogWarning("标签建议超时，使用关键词回退");
            return GenerateFallbackSuggestions(title);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "标签建议失败");
            return GenerateFallbackSuggestions(title);
        }
    }

    /// <summary>
    /// 基于完整会话内容建议标签（深度分析）
    /// </summary>
    /// <param name="sessionId">会话 ID</param>
    /// <param name="ct">取消令牌</param>
    /// <returns>标签建议列表</returns>
    public async Task<List<TagSuggestion>> SuggestFromContentAsync(
        Guid sessionId,
        CancellationToken ct = default)
    {
        var session = await _sessionRepository.GetByIdAsync(sessionId, ct);
        var messages = await _messageRepository.GetBySessionAsync(sessionId, ct);

        if (session == null || messages.Count < 5)
        {
            _logger.LogDebug("会话消息不足，跳过深度分析: {SessionId}", sessionId);
            return new List<TagSuggestion>();
        }

        var recentMessages = messages.TakeLast(20);
        var context = BuildContext(session, recentMessages);

        var prompt = $@"
分析以下会话内容，生成 3-5 个最合适的标签：

{context}

要求：
1. 标签准确反映会话主题和内容
2. 考虑技术栈、问题类型、紧急程度等维度
3. 每个标签附带颜色和 Emoji

返回 JSON 数组（最多 5 个）：
[
  {{""tag"": ""python"", ""color"": ""#3776AB"", ""emoji"": ""🐍""}},
  {{""tag"": ""urgent"", ""color"": ""#DC2626"", ""emoji"": ""⚡""}},
  ...
]

只返回 JSON 数组，不要其他解释。
";

        using var timeoutCts = new CancellationTokenSource(TimeSpan.FromSeconds(10));
        using var linkedCts = CancellationTokenSource.CreateLinkedTokenSource(ct, timeoutCts.Token);

        try
        {
            var response = await _llmClient.GenerateAsync(prompt, linkedCts.Token);
            return ParseTagSuggestions(response);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "内容标签建议失败: {SessionId}", sessionId);
            return new List<TagSuggestion>();
        }
    }

    /// <summary>
    /// 应用标签建议
    /// </summary>
    public async Task ApplySuggestionsAsync(
        Guid sessionId,
        List<TagSuggestion> suggestions,
        CancellationToken ct = default)
    {
        var existingTags = await _tagRepository.GetBySessionAsync(sessionId, ct);
        var totalTags = existingTags.Count + suggestions.Count;

        if (totalTags > 5)
        {
            throw new ValidationException("每个会话最多只能有 5 个标签");
        }

        foreach (var suggestion in suggestions)
        {
            var tag = SessionTag.Create(
                sessionId,
                suggestion.Tag,
                TagSource.Auto,
                suggestion.Color,
                suggestion.Emoji
            );

            try
            {
                await _tagRepository.AddAsync(tag, ct);
            }
            catch (DbUpdateException ex) when (IsUniqueConstraintViolation(ex))
            {
                _logger.LogDebug("标签已存在，跳过: {Tag}", suggestion.Tag);
            }
        }
    }

    private List<TagSuggestion> GenerateFallbackSuggestions(string title)
    {
        var suggestions = new List<TagSuggestion>();

        var titleLower = title.ToLowerInvariant();

        if (titleLower.Contains("bug"))
            suggestions.Add(new("bug", "#EF4444", "🐛"));

        if (titleLower.Contains("urgent") || titleLower.Contains("紧急"))
            suggestions.Add(new("urgent", "#DC2626", "⚡"));

        if (titleLower.Contains("python"))
            suggestions.Add(new("python", "#3776AB", "🐍"));

        if (titleLower.Contains("work") || titleLower.Contains("工作"))
            suggestions.Add(new("work", "#3B82F6", "💼"));

        return suggestions;
    }

    private string BuildContext(Session session, IEnumerable<Message> messages)
    {
        var sb = new StringBuilder();
        sb.AppendLine($"会话标题: {session.Title}");
        sb.AppendLine($"创建时间: {session.CreatedAt:yyyy-MM-dd}");
        sb.AppendLine("最近对话:");

        foreach (var msg in messages)
        {
            var preview = msg.Content.Length > 200
                ? msg.Content.Substring(0, 200) + "..."
                : msg.Content;
            sb.AppendLine($"{msg.Role}: {preview}");
        }

        return sb.ToString();
    }
}
```

```csharp
namespace GeneralAgent.Application.Services;

/// <summary>
/// 后台任务服务
/// </summary>
public sealed class BackgroundTaskService : IHostedService, IDisposable
{
    private readonly ConcurrentQueue<BackgroundTask> _taskQueue = new();
    private readonly SmartTagService _tagService;
    private readonly ILogger<BackgroundTaskService> _logger;
    private Timer? _timer;

    public Task StartAsync(CancellationToken ct)
    {
        _logger.LogInformation("后台任务服务启动");
        _timer = new Timer(ProcessQueue, null, TimeSpan.Zero, TimeSpan.FromSeconds(10));
        return Task.CompletedTask;
    }

    public Task StopAsync(CancellationToken ct)
    {
        _logger.LogInformation("后台任务服务停止");
        _timer?.Change(Timeout.Infinite, 0);
        return Task.CompletedTask;
    }

    /// <summary>
    /// 入队标签分析任务
    /// </summary>
    public void EnqueueTagAnalysis(Guid sessionId, int messageCount)
    {
        // 只有消息数达到阈值才入队（5, 10, 15, 20...）
        if (messageCount >= 5 && messageCount % 5 == 0)
        {
            _taskQueue.Enqueue(new TagAnalysisTask(sessionId));
            _logger.LogDebug("标签分析任务已入队: {SessionId}, 消息数: {Count}",
                sessionId, messageCount);
        }
    }

    private async void ProcessQueue(object? state)
    {
        while (_taskQueue.TryDequeue(out var task))
        {
            try
            {
                await task.ExecuteAsync(_tagService);
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "后台任务执行失败: {TaskType}", task.GetType().Name);
            }
        }
    }

    public void Dispose()
    {
        _timer?.Dispose();
    }
}

/// <summary>
/// 后台任务基类
/// </summary>
public abstract record BackgroundTask
{
    public abstract Task ExecuteAsync(SmartTagService tagService);
}

/// <summary>
/// 标签分析任务
/// </summary>
public sealed record TagAnalysisTask(Guid SessionId) : BackgroundTask
{
    public override async Task ExecuteAsync(SmartTagService tagService)
    {
        var suggestions = await tagService.SuggestFromContentAsync(SessionId);

        if (suggestions.Any())
        {
            await tagService.ApplySuggestionsAsync(SessionId, suggestions);
        }
    }
}
```

**设计说明**:
- 简单的内存队列（不依赖外部消息队列）
- 每 10 秒处理一批任务
- 失败任务记录日志但不重试
- 任务触发条件：消息数达到 5、10、15、20...

## 📊 性能优化

### 查询缓存优化

**LRU 缓存设计**:
```csharp
public class SearchQueryCache : ISearchQueryCache
{
    private readonly LinkedList<CacheEntry> _lruList = new();
    private readonly Dictionary<string, LinkedListNode<CacheEntry>> _cache = new();
    private readonly int _capacity = 100;
    private readonly TimeSpan _ttl = TimeSpan.FromHours(1);

    public SearchQuery? Get(string query)
    {
        if (_cache.TryGetValue(query, out var node))
        {
            if (DateTime.UtcNow - node.Value.Timestamp < _ttl)
            {
                // 移到链表头部（最近使用）
                _lruList.Remove(node);
                _lruList.AddFirst(node);
                return node.Value.Query;
            }

            // 过期，移除
            _cache.Remove(query);
            _lruList.Remove(node);
        }

        // 尝试相似查询匹配（Levenshtein 距离 < 3）
        foreach (var (cachedQuery, cachedNode) in _cache)
        {
            if (LevenshteinDistance(query, cachedQuery) < 3)
            {
                return cachedNode.Value.Query;
            }
        }

        return null;
    }

    public void Set(string query, SearchQuery searchQuery)
    {
        if (_cache.ContainsKey(query))
        {
            // 更新现有项
            var node = _cache[query];
            node.Value = new CacheEntry(searchQuery, DateTime.UtcNow);
            _lruList.Remove(node);
            _lruList.AddFirst(node);
        }
        else
        {
            // 添加新项
            if (_cache.Count >= _capacity)
            {
                // 淘汰最久未使用的项
                var lastNode = _lruList.Last!;
                _cache.Remove(lastNode.Value.Query.NaturalQuery);
                _lruList.RemoveLast();
            }

            var newNode = new LinkedListNode<CacheEntry>(
                new CacheEntry(searchQuery, DateTime.UtcNow)
            );
            _lruList.AddFirst(newNode);
            _cache[query] = newNode;
        }
    }
}

record CacheEntry(SearchQuery Query, DateTime Timestamp);
```

### FTS5 查询优化

**使用 FTS5 的 MATCH 操作符**:
```csharp
public async Task<List<Message>> SearchWithFTSAsync(
    string query,
    CancellationToken ct = default)
{
    // 使用 FTS5 全文搜索
    var sql = @"
        SELECT m.id, m.session_id, m.role, m.content, m.created_at
        FROM messages m
        JOIN messages_fts f ON m.id = f.message_id
        WHERE messages_fts MATCH @query
        ORDER BY rank
        LIMIT @limit
    ";

    return await _context.Messages
        .FromSqlRaw(sql, new { query, limit = 50 })
        .ToListAsync(ct);
}
```
