## 🐛 已知问题列表

### 轻微问题

1. **历史文件大小**
   - 现象：5000 条历史约 500KB
   - 影响：低
   - 解决方案：已实现自动截断

2. **Windows 颜色支持**
   - 现象：旧版 Windows 终端不显示颜色
   - 影响：中
   - 解决方案：建议使用 Windows Terminal

### 限制

1. **ReadLine 库**
   - Ctrl+L 清屏不支持（使用 /clear 代替）
   - 影响：低

2. **技能缓存**
   - 技能文件修改需要重启才能刷新
   - 影响：低（开发时）

## 🚀 快速验收脚本

### 自动化测试脚本

```bash
#!/bin/bash
# V3 UAT Quick Test Script

echo "=== General Agent V3 UAT ==="
echo ""

# 1. 构建测试
echo "1. 构建项目..."
cd v3
dotnet build --verbosity quiet
if [ $? -eq 0 ]; then
    echo "✓ 构建成功"
else
    echo "✗ 构建失败"
    exit 1
fi

# 2. 单元测试
echo ""
echo "2. 运行单元测试..."
dotnet test --no-build --verbosity quiet
if [ $? -eq 0 ]; then
    echo "✓ 所有测试通过"
else
    echo "✗ 测试失败"
    exit 1
fi

# 3. CLI 命令测试
echo ""
echo "3. 测试 CLI 命令..."

cd src/GeneralAgent.Hosts.Console

# 创建会话
SESSION_OUTPUT=$(dotnet run -- new --title "UAT测试会话" --format json)
echo "✓ 创建会话"

# 列出会话
dotnet run -- list --limit 5 > /dev/null
echo "✓ 列出会话"

# 4. 性能测试
echo ""
echo "4. 性能测试..."

# REPL 启动时间
START_TIME=$(date +%s%N)
timeout 2 dotnet run > /dev/null 2>&1 &
REPL_PID=$!
sleep 0.5
kill $REPL_PID 2>/dev/null
END_TIME=$(date +%s%N)
DURATION=$(( ($END_TIME - $START_TIME) / 1000000 ))

if [ $DURATION -lt 500 ]; then
    echo "✓ REPL 启动时间: ${DURATION}ms (< 500ms)"
else
    echo "⚠ REPL 启动时间: ${DURATION}ms (目标 < 500ms)"
fi

echo ""
echo "=== UAT 完成 ==="
echo "详细测试请参考 V3_UAT_PLAN.md"
```
