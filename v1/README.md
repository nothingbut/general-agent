# General Agent V1 (Python)

这是 General Agent 的 Python 实现版本（第一版）。

## 目录结构

```
v1/
├── src/               # 源代码
├── tests/             # 测试
├── skills/            # 技能定义
├── config/            # 配置文件
├── examples/          # 示例代码
├── templates/         # Web 模板
├── static/            # 静态资源
├── pyproject.toml     # Python 项目配置
└── requirements.txt   # 依赖列表
```
